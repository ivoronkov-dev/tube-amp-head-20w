# Ламповый гитарный усилитель 20 Вт (head)

Двухтактный двухканальный ламповый гитарный усилитель типа **head** с двумя
независимыми трактами управления тембром и выходом на наушники.

| | |
|---|---|
| **Выходная мощность** | 20 Вт |
| **Топология** | двухтактная (push-pull) |
| **Каналы** | Clean / Overdrive, независимые тракты темброблока |
| **Габариты** | 520 × 200 × 250 мм (Ш×Г×В) |
| **Ментор** | Алтынов Алексей Владимирович |
| **Команда** | Воронков Иван Сергеевич, Б04-508 |

## Цель проекта

Создать двухканальный (Clean и Overdrive) ламповый гитарный усилитель типа head
мощностью 20 Вт с двумя независимыми трактами управления тембром и выходом на
наушники.

## Функционал

**Два независимых канала**

- **Clean** — чистый канал: Bass, Middle, Treble, Volume, Bright.
- **Overdrive** — канал перегруза: Gain, Bass, Middle, Treble, Presence, Volume, Bright.

**Коммутация**

- **Вход** — Jack 6.3 мм для подключения гитары.
- **Footswitch** — Jack 6.3 мм для педали переключения каналов.
- **Выходы** — Jack 6.3 мм на 8 / 16 Ом для акустических кабинетов; Jack 3.5 мм для наушников.
- **Тумблеры** — Power, Channel, Phones; у каждого своя светодиодная индикация.

## Задачи проекта

1. Согласование принципиальной электрической схемы.
2. Выбор и закупка элементной базы.
3. Проектирование и изготовление шасси.
4. Сборка и первичное включение, проверка работы.
5. Регулировка параметров.
6. Тестирование функционала, проверка работы обоих каналов.
7. Изготовление корпуса.

Статус задач отслеживается в разделе Issues.
